The dev-aware difference

Dropbox and iCloud don't know what node_modules is. They'll happily try to sync 50,000 tiny files, crash the sync client, and clog your bandwidth. DriveWare ships with battle-tested ignore rules for every major language and framework, plus git- and DB-aware snapshots:

# Skipped by default (regenerable, safe to drop): node_modules/ .venv/ venv/ env/ target/ dist/ build/ .next/ .nuxt/ .turbo/ __pycache__/ *.pyc .cache/ .pytest_cache/ .git/objects/pack/ (refs still sync) .DS_Store *.log *.tmp # Captured at archive time (git-aware): branch, commit SHA, dirty status, remotes, tags # DB-aware: SQLite → consistent online-backup snapshots Postgres / Mongo → warning to pg_dump / mongodump first # Build-aware: Detects active webpack / vite / cargo / tsc → prompts before syncing
